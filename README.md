# LLM Stock Portfolio Analyzer — Security Analysis
A deliberately vulnerable GenAI application that simulates an AI-powered 
stock portfolio advisor. Built to demonstrate and analyse the OWASP Top 10 
for LLM Applications in a realistic (probably not) financial app context.

## Personal Goal and Notes
I will be using Claude to assist with this project in regards to consolidating my findings and creating the mock application. 

My goal of this project is to improve technical coding skills, understand security vulnerabilities, and **get my hands dirty** regarding LLMs. 

I will try to properly record what I learnt so I can come back to refresh technical concepts and such.

I aim to push two versions of the mock application: vulnerable and hardened. (Am not too sure how viable this it, might change later - 12/5/2026)

## Repository Structure
- `vulnerable/` — App with vulnerabilities intentionally present
- `hardened/` — Same app with mitigations applied
- `report/` — Writeup with reproduction steps and mitigations per vulnerability
